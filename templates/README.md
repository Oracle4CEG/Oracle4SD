# Reusable README templates

Copy the templates into a new project's actual README and metadata files.

**First-author task:** Replace every AUTHOR INPUT with verified information. Remove inapplicable prompts with a reason. Do not upload an unfinished card, licence or Croissant skeleton as a release.

**Start with:** [PROJECT_README.md](PROJECT_README.md).


## Author inputs for the completed project

| Item | Fill with verified information |
|---|---|
| Scientific purpose and observation unit | AUTHOR INPUT |
| Exact inputs, versions and source/DOI URLs | AUTHOR INPUT |
| Permanent GitHub code or folder links | AUTHOR INPUT |
| Commands, parameters and manual prerequisites | AUTHOR INPUT |
| Expected output paths, counts and units | AUTHOR INPUT |
| Access, rights, limitations and untested dimensions | AUTHOR INPUT |
| Independent check and evidence location | AUTHOR INPUT |

**Done when:** No unresolved author placeholders remain in the project release.

**Requirement mapping:** [documentation and availability](https://www.nature.com/sdata/submission-guidelines); [complete metadata](https://neurips.cc/Conferences/2026/EvaluationsDatasetsHosting); [dataset cards](https://huggingface.co/docs/hub/datasets-cards).
