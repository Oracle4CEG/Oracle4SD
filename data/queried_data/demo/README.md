# Synthetic teaching fixture

These invented groups, times and temperatures demonstrate the queried data
stage. They are not field observations, Oracle data, human-subject data or scientific findings.
The existing repository [MIT licence](../../../LICENSE) covers this teaching material;
each real project must document its own data rights.

Read the [stage instructions](../README.md). The initial fixture contains eight rows;
one exact duplicate and one intentionally out-of-range value exercise processing rules.
Processing retains one missing value and produces six rows. Its arbitrary range rule
is not a scientific recommendation.
