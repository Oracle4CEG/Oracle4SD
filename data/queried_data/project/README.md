# Project data placeholder

Add the project's permitted queried data here, or document its actual archival
location in the manifest. No research data have been supplied.
This path is ignored by Git by default except for this README. After reviewing rights
and size, explicitly add only approved small files, or keep a versioned archival link.
Record checksums so external large files remain reproducible.

Follow the [parent instructions](../README.md), [Scientific Data data policy](https://www.nature.com/sdata/policies/data-policies)
and [NeurIPS hosting requirements](https://neurips.cc/Conferences/2026/EvaluationsDatasetsHosting). Future Hugging Face packaging uses an explicit
file allowlist; it does not upload this entire repository.
