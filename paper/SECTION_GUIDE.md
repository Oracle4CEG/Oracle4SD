# Data Descriptor section guide

Follow [Scientific Data's current instructions](https://www.nature.com/sdata/submission-guidelines), not assumptions from an older template.
This is an author checklist, not manuscript prose.

| Section | Write and substantiate |
|---|---|
| Title and abstract | Descriptive title within 110 characters; abstract target 170 words; verified resource/coverage and reuse scope |
| Background & Summary | Plain-language need; relevant resources; actual contribution; overlap and limitations |
| Methods | Exact inputs, sampling, permissions, measurement/annotation, transformations and reproducible configuration |
| Data Records | Deposited files, formats, relationships, identifiers and complete dictionary |
| Data Overview, optional | One paragraph and 1–2 descriptive displays if needed |
| Technical Validation | Quality claims, references, sampling, denominators, uncertainty, failures and independent reproduction |
| Usage Notes, optional | Practical access, interpretation, appropriate handling and limits |
| Data Availability | Repeat essential data identifiers and access conditions |
| Code Availability | Exact code/version and restrictions; place immediately before references |
| References | Verified literature and data citations; embed final LaTeX references in the TEX file |
| Declarations | Actual contributions, interests, acknowledgements, funding and applicable ethics |

For SNAPP, contributions, interests and acknowledgements are collected in the portal;
Funding stays in the manuscript. Keep verified declarations in the preprint.
Cross-reference [the first-author guide](../docs/FIRST_AUTHOR_GUIDE.md),
[source-to-output map](../metadata/result_index.template.json) and
[requirements](../docs/REQUIREMENTS.md). Extended substantive analyses need a suitable
research-paper format. A separate NeurIPS submission must use that venue's actual template.
