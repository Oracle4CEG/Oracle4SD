# Workflow and packaging entry points

Run [run_pipeline.py](run_pipeline.py) for the complete offline teaching example.
Run [check_template.py](check_template.py) for repository structure, Markdown links and
code/notebook syntax. Run [prepare_huggingface.py](prepare_huggingface.py) to prepare an
allowlisted local bundle; it does not upload.

Adapt the actual scientific stage code, configuration, metadata and expected evidence for
each project. See [Scientific Data](https://www.nature.com/sdata/submission-guidelines), [NeurIPS reproducibility](https://neurips.cc/public/guides/PaperChecklist) and
[the Hugging Face preparation guide](../docs/HUGGING_FACE.md).
